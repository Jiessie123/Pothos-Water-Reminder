# Pothos-Water-Reminder
🪴 绿萝浇水提醒 · 桌面小工具
一个零安装、单文件的桌面挂件，专门提醒你给绿萝浇水。
怎么用
1. 双击打开 绿萝浇水提醒.html（用浏览器即可，无需安装任何东西）。
2. 按 F11 可全屏常驻；或直接把小窗口拖到屏幕角落。
3. 双击小窗口顶部的绿色标题栏 → 打开设置面板：
  - 浇水间隔（默认 3 天，绿萝一般 3–5 天浇一次，可自调）
  - 声音提醒、桌面弹窗通知开关
4. 给绿萝浇完水，点 💧 已浇水，倒计时重新开始，并记入“浇水记录”。
5. 暂时没空？点 稍后 让它 1 小时后再提醒。
怎么“固定在桌面最上层”
- Linux：运行 置顶启动.sh，会用 --always-on-top 把窗口真正钉在最上层。
- Windows / macOS：用浏览器打开后，按下 F11 全屏常驻；或把窗口拖到角落平时不打扰的位置。
  - 想更彻底可装个“始终置顶”小工具（如 Windows 的 DeskPins、macOS 的 Rectangle）把窗口钉住。
功能
- ⏳ 实时倒计时（天/时/分），到点变红、抖动、图标变蔫
- 🔔 到点弹桌面通知 + 播放轻快三声提示音
- 📋 浇水记录（最近 30 次，标“晚”表示逾期才浇）
- 📍 拖动位置自动记住，下次打开还在原位
- 💾 数据存在浏览器本地（localStorage），不上传、不联网
小知识
绿萝喜湿润但怕积水，土表发白、叶子稍软就是该浇水的信号；冬季可拉长到 5–7 天。
